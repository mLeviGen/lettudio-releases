# Lettudio — сборки

Готовые сборки музыкального плеера Lettudio для Android и Windows.

- `lettudio-X.Y.Z-android.apk` — почти все телефоны (arm64)
- `lettudio-X.Y.Z-android-armv7.apk` — старые 32-битные телефоны
- `lettudio-X.Y.Z-windows-x64.zip` — Windows

Последняя версия: [Releases](https://github.com/mLeviGen/lettudio-releases/releases/latest).
